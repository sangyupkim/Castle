# 🖼 그림 넣는 법

이 폴더가 게임 그림이 들어가는 곳입니다. **파일을 넣고 매니페스트 한 줄을 켜면 끝**입니다.

지금 들어 있는 타일과 타워는 **자리 잡아두려고 코드로 만든 임시 그림**입니다.
같은 이름으로 덮어쓰면 그대로 바뀝니다 — 코드는 건드릴 필요 없습니다.

---

## 3단계

### 1. 파일을 넣는다

```
assets/images/
├── manifest.js        ← 어떤 파일을 읽을지 정하는 목록
├── tiles/             ← 상단 격자 타일
│   ├── ground.png
│   ├── path.png
│   └── ...
└── towers/            ← 타워
    ├── arrow_1.png
    └── ...
```

### 2. `manifest.js`에서 그 줄의 `//`를 지운다

```js
window.SPRITE_FILES = {
  'tile.ground': 'tiles/ground.png',      // ← 켜짐
  // 'tile.path': 'tiles/path.png',       // ← 꺼짐 (예전 도형으로 그려짐)
};
```

목록에 없는 것은 **자동으로 예전 이모지·도형 렌더로 떨어집니다.**
그래서 한 장씩 늘려가도 게임은 계속 돌아갑니다. 다 채울 필요 없습니다.

### 3. 새로고침

콘솔에 `[스프라이트] {불러옴: 22, 실패: 0, ...}`이 찍힙니다.
언제든 콘솔에서 `Sprites.report()`로 다시 확인할 수 있습니다.

## 파일 이름과 크기

**크기는 전부 @2x입니다.** 캔버스가 DPR 2로 렌더되기 때문에, @1x로 넣으면 흐려집니다.

### 타일 — `tiles/`

한 칸이 화면에서 **53 × 50**이므로 파일은 **106 × 100**.
칸을 꽉 채우게 그리고, 사방 이음이 자연스럽게 반복되도록 만들어주세요.

| 파일 | 키 | 쓰이는 곳 | 필수 |
|---|---|---|---|
| `ground.png` | `tile.ground` | 타워를 놓는 빈 칸 (63칸 중 대부분) | ✅ |
| `ground2.png` | `tile.ground2` | 빈 칸 변형 — 있으면 섞어서 깝니다 | |
| `path.png` | `tile.path` | 적이 지나는 길 | ✅ |
| `path_corner.png` | `tile.path_corner` | 길이 꺾이는 칸 — 없으면 `path`를 씁니다 | |
| `path_cross.png` | `tile.path_cross` | ∞자 교차 구간 (가운데 세로줄) | |
| `start.png` | `tile.start` | 적이 나오는 곳 (위쪽 가운데) | |
| `base.png` | `tile.base` | 지켜야 하는 기지 (아래쪽 가운데) | |

> `ground`와 `path` 두 장만 넣어도 화면 전체가 바뀝니다. 나머지는 있으면 좋은 것들입니다.

### 타워 — `towers/`

화면에서 **48 × 56** → 파일은 **96 × 112**.
세로가 칸 높이(50)보다 크므로 **타워가 칸 위로 솟습니다** — 이게 입체감의 대부분입니다.

- 배경은 **투명(알파)** 이어야 합니다
- **발밑이 파일 아래쪽 끝에 닿게** 그려주세요 (바닥선 기준으로 배치합니다)
- 그림자는 그림 안에 그려 넣으면 자연스럽습니다

| 타워 | 파일 | 색 계열 |
|---|---|---|
| 🏹 화살탑 | `arrow_1.png` `arrow_2.png` `arrow_3.png` | 초록 |
| ❄️ 서리탑 | `frost_1~3.png` | 하늘 |
| 💣 대포탑 | `cannon_1~3.png` | 주황 |
| 🎯 저격탑 | `sniper_1~3.png` | 자홍 |
| ⚡ 번개탑 | `tesla_1~3.png` | 청록 |

**뒤의 숫자는 레벨 묶음입니다** — `_1`은 Lv1~2, `_2`는 Lv3~4, `_3`은 Lv5.
**`_1` 한 장만 넣어도 모든 레벨에서 그 그림을 씁니다.** 여유가 생기면 위 티어를 추가하세요.

## 다음 단계 이름 규칙

지금은 안 켜져 있지만 코드는 이미 이 이름들을 찾습니다. 파일만 넣고 매니페스트에 추가하면 됩니다.

| 대상 | 키 | 예시 |
|---|---|---|
| 아레나 용병 | `unit.<아이디>` | `unit.swordsman` `unit.archer` `unit.healer` `unit.guardian` `unit.mage` `unit.rogue` `unit.paladin` `unit.marksman` |
| 영웅 (각인별) | `hero.<각인>` | `hero.blade` `hero.warden` `hero.sorcerer` |
| 아레나 몬스터 | `mob.<아이디>` | `mob.goblin` `mob.hound` `mob.orc` `mob.darkarch` `mob.ogre` `mob.boss` |

아레나 개체는 **발밑 기준**으로, 몸 반지름의 약 2.1배 너비 × 2.7배 높이로 그려집니다.
가장 흔한 반지름이 13.9px이므로 화면에서 **약 29 × 38** → 파일은 **58 × 76 (@2x)** 정도가 맞습니다.

## 그림 구할 만한 곳

전부 상업 이용 가능하고 출처 표기 조건이 느슨한 곳들입니다. **받기 전에 각 에셋의 라이선스를 직접 확인하세요.**

| 곳 | 특징 |
|---|---|
| [Kenney](https://kenney.nl/assets) | CC0 (완전 자유). 타워디펜스 팩이 있고 스타일이 일관돼서 섞어 쓰기 좋습니다 |
| [itch.io 에셋](https://itch.io/game-assets/free/tag-tower-defense) | 무료·유료 혼재. 픽셀아트가 많습니다 |
| [OpenGameArt](https://opengameart.org) | 라이선스가 제각각이니 항목마다 확인 필요 |
| [Game-icons.net](https://game-icons.net) | CC BY. UI 아이콘 4,000종 — Tier 3에 딱 맞습니다 |

받은 파일이 규격과 다르면 그대로 넣어도 됩니다 — 코드가 지정한 크기로 늘려 그립니다.
다만 **가로세로 비율이 크게 다르면 찌그러지므로**, 타워는 대략 6:7, 타일은 정사각에 가깝게 잘라 쓰는 편이 좋습니다.

## 안 나올 때

| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 바뀜 | `manifest.js`에서 `//`를 지웠는지 · 파일명 대소문자 |
| 콘솔에 `실패: n` | 그 파일 경로가 틀렸습니다 — `없는파일` 목록에 경로가 찍힙니다 |
| 흐릿함 | @1x로 넣었습니다. 두 배 크기로 다시 |
| 타워가 칸에 안 맞음 | 배경이 투명한지 · 발밑이 파일 아래쪽 끝에 닿는지 |
| 로딩 화면이 안 끝남 | 파일 하나가 응답이 없는 경우입니다. 해당 줄을 잠시 꺼보세요 |
