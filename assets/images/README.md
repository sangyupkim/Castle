# 🖼 그림 넣는 법

이 폴더가 게임 그림이 들어가는 곳입니다. **파일을 넣고 매니페스트 한 줄을 켜면 끝**입니다.

지금은 받아온 픽셀 아트 세 묶음이 적용돼 있습니다.

| 폴더 | 출처 묶음 | 쓰는 곳 |
|---|---|---|
| `tiles/field_00~19.png` | `downloads/1 Tiles` | 상단 밭 (타워 놓는 칸) · 아레나 바닥 |
| `tiles/grass.png` | 〃 | 적이 지나는 잔디 길 |
| `tiles/castle.png` | `downloads/Simple Tower Defense` | 지켜야 하는 기지 (4프레임 깃발) |
| `towers/*.png` | 〃 | 타워 5종 |
| `proj/*.png` | 〃 | 투사체 5종 |
| `mobs/{slime,orc,wolf,bee}/` | `downloads/free-field-enemies-…` | 몬스터 4종 × 3방향 × 애니 |

> ⚠️ **라이선스는 직접 확인해서 여기에 적어두세요.** 세 묶음 모두 배포 조건을 알 수 있는
> 파일이 함께 오지 않았습니다. 출처 URL과 라이선스(예: CC0 / CC BY / 상업 이용 가부)를
> 아래에 남겨두면 나중에 배포할 때 찾아 헤매지 않습니다.
>
> - `1 Tiles` — 출처: ____ · 라이선스: ____
> - `Simple Tower Defense` — 출처: ____ · 라이선스: ____
> - `free-field-enemies-pixel-art-for-tower-defense` — 출처: ____ · 라이선스: ____

원본은 `downloads/`에 그대로 뒀습니다. 게임이 읽는 것은 위 표의 정리된 파일들입니다.

---

## 3단계


### 1. 파일을 넣는다

```
assets/images/
├── manifest.js   ← 무엇을 읽을지 정하는 목록
├── tiles/        ← 밭 · 잔디 길 · 성
├── towers/       ← 타워 5종
├── proj/         ← 투사체 5종
├── mobs/         ← 몬스터 (방향별 스프라이트시트)
└── downloads/    ← 받아온 원본 (게임이 읽지 않음)
```

### 2. `manifest.js`에서 그 줄의 `//`를 지운다

```js
window.SPRITE_FILES = {
  'tile.ground': 'tiles/ground.png',      // ← 켜짐
  // 'tile.path': 'tiles/path.png',       // ← 꺼짐 (예전 도형으로 그려짐)
};
```

목록에 없는 것은 **자동으로 예전 이모지·도형 렌더로 떨어집니다.**
그래서 한 장씩 늘려가도 게임은 계속 돌아갑니다. 다 채울 필요 없습니다.

### 3. 새로고침

콘솔에 `[스프라이트] {불러옴: 22, 실패: 0, ...}`이 찍힙니다.
언제든 콘솔에서 `Sprites.report()`로 다시 확인할 수 있습니다.

## 파일 이름과 크기

원본 픽셀 아트는 작습니다(타일 32px, 타워 16~18px, 몬스터 프레임 48px).
**보간을 끄고 정수배에 가깝게 확대**하므로 원본 그대로 넣으면 됩니다 — 미리 키울 필요 없습니다.

### 타일 — `tiles/`

| 파일 | 키 | 원본 | 쓰는 곳 |
|---|---|---|---|
| `field_00~19.png` | `tile.field.0~19` | 32×32 | 빈 칸. 칸 좌표로 골라 깔아 격자가 안 보입니다 |
| `grass.png` | `tile.path` · `tile.start` | 32×32 | 적이 지나는 길 |
| `castle.png` | `tile.base` | 208×38 (52×38 ×4) | 기지. 깃발이 나부낍니다 |

### 타워 — `towers/`

`arrow` `frost` `cannon` `sniper` `tesla` — 원본 비율 그대로 2.2배로 세웁니다.
배경은 투명, **발밑이 파일 아래쪽 끝에 닿게** 그려져 있어야 칸에 붙습니다.
`_1`(Lv1~2) `_2`(Lv3~4) `_3`(Lv5) 세 티어를 쓸 수 있고, 지금은 `_1` 한 장씩만 넣어 모든 레벨이 같습니다.

### 투사체 — `proj/`

타워와 같은 이름 5종. 날아가는 방향으로 돌려 그립니다.

### 몬스터 — `mobs/<이름>/`

`<방향>_<동작>.png` — 방향은 `S`(옆) `D`(아래·이쪽) `U`(위·저쪽), 동작은 `Walk` `Attack` `Death`.
가로로 이어 붙인 6프레임짜리 스프라이트시트입니다.

매니페스트의 `SPRITE_ACTORS`에 프레임 크기와 함께 두 값을 적습니다.

| 값 | 뜻 |
|---|---|
| `foot` | 프레임 안에서 발이 닿는 y. 이 선을 몸 아래에 맞춥니다 |
| `head` | 그림이 실제로 시작하는 y. 체력바와 등급 표시를 여기 위에 놓습니다 |

48px 프레임 안에서 캐릭터는 13~22px밖에 안 차지해서, 이 두 값이 없으면
체력바가 허공에 뜨고 발이 땅에서 떨어집니다.

### 그림 넷으로 몬스터 열넷

게임에는 상단 8종 + 아레나 6종이 있는데 그림은 넷뿐입니다.
`js/sprites.js`의 `MOB_ACTORS`가 **크기와 색**으로 갈라 씁니다 —
같은 오크라도 회색으로 크게 그리면 강철오크, 붉게 더 크게 그리면 보스입니다.
색은 곱하기로 입혀서 원본의 명암이 그대로 남고, 처음 쓸 때 한 번만 계산해 캐시에 남습니다.

```js
brute:  { actor:'orc', h:1.05, tint:'#9aa6bb' },   // 강철오크
boss:   { actor:'orc', h:1.15, tint:'#e05555' },   // 던전보스
bounty: { actor:'orc', h:1.05, tint:'#f5c542' },   // 현상수배
```

새 그림이 생기면 이 표에서 해당 줄을 지우고 `SPRITE_ACTORS`에 배우를 추가하면 됩니다.

넣는 법은 몬스터와 같습니다(`SPRITE_ACTORS`에 배우 추가).

## 그림 구할 만한 곳

전부 상업 이용 가능하고 출처 표기 조건이 느슨한 곳들입니다. **받기 전에 각 에셋의 라이선스를 직접 확인하세요.**

| 곳 | 특징 |
|---|---|
| [Kenney](https://kenney.nl/assets) | CC0 (완전 자유). 타워디펜스 팩이 있고 스타일이 일관돼서 섞어 쓰기 좋습니다 |
| [itch.io 에셋](https://itch.io/game-assets/free/tag-tower-defense) | 무료·유료 혼재. 픽셀아트가 많습니다 |
| [OpenGameArt](https://opengameart.org) | 라이선스가 제각각이니 항목마다 확인 필요 |
| [Game-icons.net](https://game-icons.net) | CC BY. UI 아이콘 4,000종 — Tier 3에 딱 맞습니다 |

받은 파일이 규격과 다르면 그대로 넣어도 됩니다 — 코드가 지정한 크기로 늘려 그립니다.
다만 **가로세로 비율이 크게 다르면 찌그러지므로**, 타워는 대략 6:7, 타일은 정사각에 가깝게 잘라 쓰는 편이 좋습니다.

## 안 나올 때

| 증상 | 확인할 것 |
|---|---|
| 아무것도 안 바뀜 | `manifest.js`에서 `//`를 지웠는지 · 파일명 대소문자 |
| 콘솔에 `실패: n` | 그 파일 경로가 틀렸습니다 — `없는파일` 목록에 경로가 찍힙니다 |
| 흐릿함 | @1x로 넣었습니다. 두 배 크기로 다시 |
| 타워가 칸에 안 맞음 | 배경이 투명한지 · 발밑이 파일 아래쪽 끝에 닿는지 |
| 로딩 화면이 안 끝남 | 파일 하나가 응답이 없는 경우입니다. 해당 줄을 잠시 꺼보세요 |
